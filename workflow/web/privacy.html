Puzzle Core 隐私政策

开发者：EasyIndie · 更新日期：2026 年 10 月 4 日

Puzzle Core 是一款几何翻滚解谜游戏。游戏无需登录，没有广告、分析或追踪 SDK，也不向开发者服务器上传玩家进度或成绩。

本机记录

游戏在你的设备上保存通关进度、最佳步数与用时、回放、当前关卡和操作偏好。这些记录用于续玩与显示你的成绩，不用于跨设备识别或广告。

选关页的“重置进度”可删除这些游戏记录。Web 版清除浏览器中的本站数据也会删除记录。删除前请留意：当前版本没有云存档或账号恢复。

主动分享

只有在你点击分享时，游戏才复制关卡链接及步数到剪贴板；是否发送以及发给谁由你决定。打开分享链接会让浏览器向 Web 托管服务请求页面。

Web 托管与外部链接

Web 版由 GitHub Pages 提供。访问网站或在线隐私政策时，托管服务可能按其政策处理 IP 地址等访问数据。这与游戏存储的本机进度不同；请参阅 GitHub 隐私声明。外部商店和平台也有各自的隐私政策。

支持与反馈

遇到问题可在 项目反馈页说明设备、浏览器或系统版本和复现步骤。该页面是公开的；请不要提交个人信息。商店版的隐私声明将以最终发布包所含功能为准；增加联网、广告或内购前会更新此政策。
