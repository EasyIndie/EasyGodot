# 13 · 手势输入改进

2026-10-04：收到移动端滑动滚错方向反馈后调整。

## 行为

- 根据相机投影得到的四个屏幕方向比较角度，方向向量先归一化，避免远近和格子大小干扰。
- 不再沿用上一手方向，也不禁止玩家明确掉头。
- 最接近的两个方向相差不足 16° 时暂不移动；保持按住，向目标斜向修正即可触发。
- 明确方向达到距离阈值立即执行，不等抬手；一次手势只执行一步。
- 阈值为屏幕格子长度的 75%，限制在 26–56 个逻辑像素；短抖动不能触发，大屏无需长拖。
- 当前运动与累计位移夹角超过 60° 时先等待，减少弯曲轨迹过早确认错误方向。
- 固定追踪第一根手指的 index，其他手指的拖动和抬起不干扰；菜单隐藏或重新取景取消旧手势。
