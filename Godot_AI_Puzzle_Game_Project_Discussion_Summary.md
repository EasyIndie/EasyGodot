# Godot + AI Agent 3D 几何解谜游戏项目讨论总结

## 一、项目定位

目标：

开发一款基于 Godot 的 3D 几何滚动解谜游戏，结合：

-   Godot
-   Pi Agent
-   GitHub
-   自动化测试
-   AI 关卡生成

产品方向：

> Shape × Space × Mechanism\
> 形状 × 空间 × 机关

核心卖点：

玩家控制可变化形态的几何体，通过移动、旋转、变形和机关组合完成关卡。

------------------------------------------------------------------------

# 二、竞品调研总结

## Bloxorz

定位：

-   经典滚动方块解谜
-   1×1×2 长方体
-   网格移动
-   进入目标洞

启发：

规则简单，但状态空间复杂。

风险：

如果只是：

> Bloxorz + 更好的画面

差异化不足。

------------------------------------------------------------------------

## Bloxzer

特点：

-   现代 3D Bloxorz 类游戏
-   Steam 分发
-   免费部分关卡 + 付费解锁

验证：

现代化 Bloxorz 仍然存在市场。

------------------------------------------------------------------------

## Bloxpath

特点：

-   大量关卡
-   多种机制
-   更强调内容规模

启发：

长期价值来自：

> 机制数量 × 关卡设计 × 内容量

------------------------------------------------------------------------

## Syncline

特点：

-   可变形 Cube
-   拆分与组合
-   多形态空间解谜

启发：

未来方向应从：

"控制一个方块"

升级为：

"控制一个可变化的几何体"。

------------------------------------------------------------------------

## Baba Is You / The Witness

启发：

简单规则可以产生大量复杂内容。

公式：

    基础规则
     ↓
    组合
     ↓
    新机制
     ↓
    大量关卡

------------------------------------------------------------------------

# 五、Puzzle Core

纯逻辑模块，不依赖视觉。

负责：

-   Shape
-   Position
-   Rotation
-   Movement
-   Collision
-   Goal Check
-   State Transition

示例：

    PuzzleState

    shape
    position
    rotation
    mechanism_state

# 八、Replay / 排名 / 社交系统

## Replay

不保存视频。

保存：

    Level
    Seed
    Input Sequence

例如：

    UP UP RIGHT DOWN

优势：

-   数据小
-   可验证
-   支持排行榜
-   支持 Ghost

------------------------------------------------------------------------

## 排行榜

指标：

### 最少步数

    World Record
    31 moves

### 最快时间

    4.82 sec

------------------------------------------------------------------------

## Ghost
